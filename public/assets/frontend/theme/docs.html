Getting Started

Welcome to Agares CMS! This guide will help you set up and start using your new content management system.

Quick Start: Sign up for a free account and you'll be creating pages in minutes!

Installation

Agares CMS is available as a cloud-hosted solution or self-hosted. Follow the appropriate guide for your setup.

Cloud Hosted (Recommended)

Bash
# Simply sign up at agares.com/signup
# No installation required!

Self-Hosted

Bash
# Clone the repository
git clone https://github.com/agares/cms.git
cd cms

# Install dependencies
npm install

# Configure environment
cp .env.example .env

# Run database migrations
npm run migrate

# Start the server
npm start

Configuration

Configure your CMS settings through the admin panel or environment variables.

ENV
# Database
DATABASE_URL=postgresql://user:password@localhost:5432/agares

# Server
PORT=3000
NODE_ENV=production

# Security
SESSION_SECRET=your-secret-key-here
JWT_SECRET=your-jwt-secret

# Email
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_USER=your-email@example.com
SMTP_PASS=your-password

Creating Pages

Learn how to create and manage pages with the visual editor.

Using the Visual Editor

  1. Navigate to Pages in the sidebar
  2. Click "Create New Page"
  3. Choose a template or start from scratch
  4. Add content blocks with drag-and-drop
  5. Customize styling and layout
  6. Publish when ready!
Pro Tip: Save drafts frequently to avoid losing your work.

Blog Setup

Set up your blog with categories, tags, and SEO optimization.

Creating Your First Post

JavaScript
// API Example: Create a blog post
const createPost = async () => {
  const response = await fetch('/api/posts', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      title: 'My First Post',
      content: 'Hello World!',
      category: 'tutorials',
      tags: ['getting-started', 'cms'],
      status: 'published'
    })
  });
  return response.json();
};

API Usage

Access your content programmatically with our REST API.

Authentication

JavaScript
// Get API token
const response = await fetch('/api/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    email: 'user@example.com',
    password: 'your-password'
  })
});

const { token } = await response.json();

// Use token in subsequent requests
fetch('/api/pages', {
  headers: {
    'Authorization': `Bearer ${token}`
  }
});
