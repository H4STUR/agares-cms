Core Feature

User Roles & Permissions

Control access with granular permission settings. Create custom roles that match your team structure and workflow.

Default Roles

Administrator

Full Access

Complete control over all aspects of the CMS including settings, users, and content management.

Editor

Content

Can create, edit, publish, and delete all content. Cannot access system settings or manage users.

Author

Own Content

Can create and publish their own posts. Cannot edit content created by other users.

Contributor

Draft Only

Can create and edit their own drafts but cannot publish. Content requires editor approval.

Custom Roles: Create unlimited custom roles with specific permission combinations to match your exact workflow needs.
